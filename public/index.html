NO BLACK BOXES

The thinking
behind the match.

Precise where it matters. Flexible where meaning matters.
A real retrieval pipeline, with every stage explained.

01

Collect & normalize

Import authorized Greenhouse boards, approved career pages with Firecrawl, or validated JSON. Preserve source links and unknown fields.

Provenance · deduplication · freshness
02

Chunk & embed

Descriptions become bounded, overlapping chunks. Job identity stays attached to every vector so passages can be traced to their source.

1,100 characters · 160 overlap
03

Filter with SQL

Country, city, work style, level, and salary are hard constraints. Both retrieval paths see the same eligible jobs. Unknown is not a match.

Parameterized queries · AND constraints
04

Retrieve two ways

Full-text retrieval finds exact terms. Vector similarity finds related concepts. Chunk matches are deduplicated into job-level candidates.

Full-text search + cosine similarity
05

Fuse & re-rank

Weighted reciprocal-rank fusion combines rankings, not incompatible raw scores. Evidence-aware ranking or an optional cross-encoder refines the shortlist.

RRF k = 60 · optional Cohere
06

Explain with sources

Read exact supporting passages and what remains unconfirmed. Optional AI excerpt selection is checked against the source before it reaches you.

Verified quotes · no invented culture scores
THIS WORKSPACE

Local, inspectable demo

The demo uses real SQLite SQL and FTS5 with a small, hand-built concept-vector index. It is not a pretrained neural embedding model. Live mode uses PostgreSQL, pgvector, and OpenAI embeddings.

No infrastructure is silently substituted. A failed live database returns an error, not fictional results.

FROM DEMO TO LIVE

Your infrastructure. Your control.

  1. Connect the database

    Run sql/001_init.sql in a PostgreSQL database with pgvector. Set DATABASE_URL on Vercel.

  2. Enable private access & embeddings

    Set APP_ACCESS_TOKEN, INGEST_TOKEN, and OPENAI_API_KEY as server-side secrets.

  3. Import, verify, then scale

    Sync authorized sources. Firecrawl, Cohere, and AI excerpt selection are optional. No paid provider is called in demo mode.
